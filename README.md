# 光学：从光与物质到纳米光学（暂定）

一部面向具备高等数学基础读者的光学读本。前半部建立直观、统一的物理图像，后半部逐渐进入纳米光学和现代研究；压缩传统几何光学内容。

## 叙事线索

- **光如何传播**：电磁场、波动、相位、偏振、干涉与衍射。
- **光如何与物质相互作用**：极化、色散、吸收、散射、荧光、激光与量子描述。
- **人们如何控制和利用光**：界面、光学模式、波导、共振、成像、通信与光学测量。
- **纳米尺度出现什么新现象**：近场、Plasmonics、纳米天线、光子晶体、Metasurfaces、拓扑及非厄米光子学。

## 编写原则

每章由具体物理问题引入，以简明模型连接不同领域，区分物理思想与技术实现。数学工具随问题引入；结合现代论文案例，但不追求传统教材知识点的简单汇总。
