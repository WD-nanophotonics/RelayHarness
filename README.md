# 光学：从光与物质到纳米光学（暂定）

一部面向具备高等数学基础、尚未系统修过光学课程的学习者的光学读本。前半部建立直观、统一的物理图像，后半部逐渐进入纳米光学和现代研究；传统几何光学从简。

## 第一章

[《光与物质的第一次相遇》](ch01/01_光与物质的相遇.md)（初稿，包含五幅可编辑的 SVG 概念示意图和三个思想实验）

## 叙事线索

- **光如何传播**：电磁场、波动、相位、偏振、干涉与衍射。
- **光如何与物质相互作用**：极化、色散、吸收、散射、荧光、激光与量子描述。
- **人们如何控制和利用光**：界面、光学模式、波导、共振、成像、通信与光学测量。
- **纳米尺度出现什么新现象**：近场、Plasmonics、纳米天线、光子晶体、Metasurfaces、拓扑及非厄米光子学。

## 编写原则

以具体的物理问题和持续出现的假想光源串联章节；通过具象的简化模型与思想实验训练物理判断；在模型旁交代假设及适用边界。保留揭示物理思想所需的推导，纯技术证明可移至附录。区别物理原理、计算实现和实验测量，并通过现代研究案例建立连接。
